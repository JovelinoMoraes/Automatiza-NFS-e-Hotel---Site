## Alterações que você precisa fazer

### 1. Link de download
No `index.html`, procure:
`<!-- EDITE O href ABAIXO COM O LINK REAL DO SEU INSTALADOR -->`

Troque o `href="#"` pelo link real do seu instalador.

### 2. Vídeo do tutorial
No `index.html`, procure o bloco `Seu tutorial em vídeo`.

Substitua o conteúdo por um iframe do YouTube, por exemplo:
`<iframe src="https://www.youtube.com/embed/SEU_VIDEO" title="Tutorial Automatiza NFS-e Hotel" allowfullscreen></iframe>`
